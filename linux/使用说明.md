# Nibble 桌面版 · Linux 使用说明

> 一句话：解压，运行，然后敲空格。
>
> **先确认包对不对**：机器是 ARM64（飞腾 / 鲲鹏等），就要 `aarch64` 结尾的那个包；
> `x86_64` 是 Intel / AMD 机器的，装错会报 `Exec format error`。
> 不确定的话，在终端里执行 `uname -m` 看输出：`aarch64` 就用 aarch64 包。

---

## 一、跑起来（不用安装）

**1. 解压**

在文件管理器里右键 `nibble-desktop-0.4.0-aarch64.tar.gz` → 「解压到此处」，得到同名文件夹。

**2. 打开终端**

进入解压出来的 `nibble-desktop-0.4.0-aarch64` 文件夹，在**空白处右键 → 「在终端中打开」**。
（这样目录已经切好了，最省事。）

如果右键菜单里没有这一项：

- 按 `Ctrl + Alt + T`；
- 或左下角开始菜单 → 搜索「终端」；
- 然后输入 `cd `（cd 后面有个空格），把刚才那个文件夹从文件管理器**拖进终端窗口**，路径会自动填上，回车。

**3. 运行**

```bash
./nibble
```

注意是英文句点加斜杠，中间**没有空格**。

> 往终端里粘贴命令要用 `Ctrl + Shift + V`，或者鼠标右键 → 粘贴（**不是** `Ctrl + V`）。

**4. 退出**

点托盘里的 Nibble 图标 → 右键 → 最下面「退出 Nibble」。
（不要用 `Ctrl + C` 硬杀。）

> 程序是常驻托盘的：关掉悬浮窗不等于退出。

---

## 二、启动之后会看到什么

**没有主界面**，这是正常的。启动后会出现两样东西：

- 桌面右下角一个约 300×220 的小窗（像素小生物和它的敌人）；
- 系统托盘里一个 Nibble 图标。

怎么玩：

| 操作 | 效果 |
| --- | --- |
| 敲**空格**或**回车** | 发起一次攻击（在哪个程序里敲都算） |
| 点小生物 / 窗口里的「武器库」「怪物库」 | 在悬浮窗上方弹出对应面板 |
| 按住窗口任意位置拖动 | 移动悬浮窗（位置会记住） |
| 悬停 HUD | 看战绩（攻击次数 / 击败数 / 连击） |
| 右键托盘图标 | 菜单：攻击一次、武器库、怪物库、暂停键盘攻击、攻击间隔、按键统计、退出 |

## 三、遇到问题

| 现象 | 原因 | 怎么办 |
| --- | --- | --- |
| `Permission denied` | 解压时丢了可执行权限 | 先 `chmod +x nibble`，再 `./nibble` |
| 报 sandbox / chrome-sandbox / SUID 相关错误 | Chromium 沙箱在国产发行版上常见的兼容问题 | 改用 `./nibble --no-sandbox` |
| 程序起来了，但敲键盘没反应 | 多半是**在 Wayland 会话下**（Nibble 靠 X11 读键盘）；也可能缺运行库 | 见下面「键盘没反应」 |
| 托盘图标找不到 | 少数桌面环境没有托盘区 | 悬浮窗会一直留在桌面上；退出用系统监视器结束 `nibble` 进程 |
| 启动时弹窗提示 Wayland | 同上 | 注销 → 登录界面右下角会话菜单选「X11」或「Ubuntu on Xorg」→ 重新登录 |

### 键盘没反应怎么查

Nibble 通过 X11 读取键盘（**只看空格和回车**）。这两种情况会让它失效：

1. **当前是 Wayland 会话** —— 注销后在登录界面切成 X11 / Xorg 会话重新登录即可，设一次就行。
2. **系统缺 X11 运行库** —— 终端里执行下面两条，把输出发给开发者：

```bash
echo "会话类型: $XDG_SESSION_TYPE"
ldd ./nibble | grep -i "not found"
```

程序本身不会因此崩溃：启动时会弹窗说明，托盘菜单里也会长期保留一条
「⚠️ 键盘监听不可用（点这里看原因）」，点它能看到具体原因。此时托盘里的
「直达 → 攻击一次」和面板里的攻击按钮仍然可用。

## 四、它做什么、不做什么

- **只监听空格与回车**两个键，用来驱动攻击；不记录其他按键、不拦截输入、不联网、没有任何统计上报。
- 数据都在本机 `~/.config/Nibble/`（存档、设置、按键统计），删除程序不会自动删掉它。
- **不需要管理员密码**，不写系统目录。
- Linux 版没有「窗口透明度」和「开机自启」入口：前者 Electron 在 Linux 上未实现，后者需要你自己配置。

---

## 五、卸载

删掉解压出来的文件夹；如果想连存档一起清掉：

```bash
rm -rf ~/.config/Nibble
```

---

反馈问题时，把**终端里的报错原文**和下面几条的输出一起发过来，能省很多来回：

```bash
uname -m
ldd --version | head -1          # glibc 版本
echo $XDG_SESSION_TYPE           # X11 还是 Wayland
```
