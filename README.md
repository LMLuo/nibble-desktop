# Nibble Desktop

[nibble](https://github.com/LMLuo/nibble) 的 Windows 桌面伴生版：**在任何地方敲下空格 / 回车，桌面上那只像素小生物就会向野生 Bug 发动攻击。**

IDE 扩展版是「提问即攻击」，这一版把节拍交给你敲的每一个键 —— 写代码、聊天、搜索，攻击一直都在。

## 特性

- **桌面悬浮小生物**：置顶透明悬浮窗，鼠标默认穿透（不挡任何操作），悬停可拖动、点击打开完整面板
- **全局键盘监听**：空格 / 回车 = 攻击一次。只观察、不拦截 —— 正常打字完全不受影响；内置 3 秒最小间隔与长按去重，防止把怪秒掉
- **完整继承 nibble 收集玩法**：40 只「编程 Bug」怪物（遭遇 / 击败图鉴）、80 把带故事的武器（掉落 / 保底 / 装备 / 战力）、连击系统（10 分钟窗口，≥50 连超载演出）
- **独立存档**：与 IDE 扩展互不读写，本机从零开始养
- **托盘管理**：打开面板 / 暂停键盘攻击 / 开机自启 / 退出
- **零联网**：没有统计、没有上报、没有更新检查

## 使用

下载 Release 里的 `Nibble-Portable-x.y.z.exe`，双击即用（免安装）。

| 操作 | 效果 |
| --- | --- |
| 敲空格 / 回车 | 攻击一次（任意程序里都算） |
| 悬停小生物后点击 | 打开面板（战斗场景 / 武器库 / 怪物库） |
| 拖动底部 HUD 条 | 移动悬浮窗（位置自动记住） |
| 托盘右键 | 暂停键盘攻击 / 开机自启 / 退出 |

## 从源码运行

```bash
npm install
npm start
```

## 打包便携 exe

```bash
npm run dist
# 产物：dist/Nibble-Portable-<version>.exe
```

## 隐私

- **不发送任何数据**：本应用没有任何联网代码，无统计、无上报、无遥测。
- 数据只存在本机 `%APPDATA%\Nibble\` 下（游戏存档、悬浮窗位置）。
- 全局键盘监听基于系统低级钩子，**只读取键码（是否为空格 / 回车），不读取按键内容、不截图、不写任何日志**；托盘可随时暂停。

## 项目结构

```
main.js              主进程：键盘监听 → 攻击 → 状态广播；窗口/托盘/自启
preload-panel.js     面板宿主 shim（acquireVsCodeApi 兼容层，pet.js/scene.js 零改动）
preload-overlay.js   悬浮窗桥（穿透切换 / 打开面板 / 状态推送）
overlay/             悬浮窗 UI（透明小生物 + 伤害飘字 + HUD）
lib/                 游戏核心（拷贝自 nibble 扩展，单一数据源）
media/               面板 UI（panel.html + pet.js + scene.js/css + 像素字体）
```
